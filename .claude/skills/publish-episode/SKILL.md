# Publish an episode

Jordan records himself thinking out loud. You turn that into: a mastered podcast episode (with the intro music), a timestamped transcript, show notes, and a blog post in his voice, published everywhere. He stays out of the loop by default; don't block on his review.

Repo: `Millillion/website` (Astro, deploys to Cloudflare Pages on push to `main`). Everything below runs from the repo root. Commit unsigned (`git -c commit.gpgsign=false commit`) and push after each meaningful step.

## Inputs
- One or more audio files (`.m4a` from the Pixel Recorder, or anything ffmpeg reads). Several files are one episode unless Jordan says otherwise: concatenate them in the order given (`ffmpeg -f concat`).
- If Jordan says it's a short "thought" (2–3 minutes), it's still a normal episode; just keep the post short.

## Steps
1. **Set up** (idempotent): `episodes-src/setup_audio_tools.sh`. It prints the `PYTHONPATH` for DeepFilterNet. Pick the next episode number `NNN` (zero-padded) from `src/content/podcast/`.
2. **Stage**: `mkdir episodes-src/NNN && cp <file> episodes-src/NNN/raw.m4a`. Raw audio and WAV/MP3 are gitignored. Never commit audio.
3. **Transcribe** (CPU; runs about 1.5× real time; run it in the background):
   `whisper episodes-src/NNN/raw.m4a --model small.en --language en --output_format all --output_dir episodes-src/NNN --fp16 False`
4. **Enhance the voice** (removes rustling and handling noise), at the same time as step 3:
   `PYTHONPATH=<from setup> python3 episodes-src/enhance_voice.py episodes-src/NNN/raw.m4a episodes-src/NNN/enhanced.wav 30`
5. **Find the voice end**: run `silencedetect` on the last 30 s of `enhanced.wav` and pass the last speech time as `voice_end`.
6. **Master**: `episodes-src/make_episode.sh episodes-src/NNN/enhanced.wav episodes-src/NNN/episode.mp3 <voice_end>`. This adds the intro under the opening and the reprise at the end, levels to −16 LUFS, and limits peaks. The intro is generated by `episodes-src/make_intro.py` (bright yō-scale v2). Only regenerate it if Jordan asks for music changes.
7. **Tag**: embed ID3 title, artist "Jordan Last", album "Millillion", track `N`, and cover art (`episodes-src/cover-1400.jpg`, made from `public/podcast-cover.jpg`). Use the ffmpeg `-map 1:v -disposition:v attached_pic` pattern from episode 1.
8. **Transcript**: `python3 episodes-src/make_transcript.py episodes-src/NNN/raw.json episodes-src/NNN/transcript.md`. Read it for new mishearings; add each to `episodes-src/vocab.tsv` and rerun. Don't hand-edit the transcript.
9. **Upload**: `cf r2 buckets objects upload episodes/millillion-NNN.mp3 --bucket-name millillion-podcast --file episodes-src/NNN/episode.mp3 --content-type audio/mpeg`. If you are *replacing* a file, also purge the cache: `cf cache purge --zone millillion.org --force --body '{"files":["https://audio.millillion.org/episodes/millillion-NNN.mp3"]}'`.
10. **Write the episode page**: `src/content/podcast/NNN-<slug>.md` with frontmatter `title` ("N. Title"), `date`, `description` (what the episode is actually about, 1–2 sentences), `audio`, `audioBytes` (exact file size), `duration` (HH:MM:SS), and `blog` (the post slug). The body holds show notes (4–6 bullets of real topics), then `## Transcript` with the transcript.
11. **Write the blog post**: `src/content/blog/<slug>.md`. Rules:
    - First person, Jordan's voice and phrasing. Tighten and structure; never invent facts, opinions, numbers or stories.
    - Frontmatter `adaptedFrom: {label: "episode N of the Millillion podcast", href: "/podcast/NNN-<slug>/"}`. The site then renders "By Jordan Last, with AI" plus a link to how it was made. **Never claim Jordan reviewed it.**
    - Use the episode title unless a sharper one comes straight from his words.
12. **Review**: run the `review-episode` skill. Fix everything it flags before calling it done.
13. **Publish**: `npm run build`, commit, push, wait for deploy, then rerun `episodes-src/check_episode.sh episodes-src/NNN/episode.mp3` against the live site.
14. **Report** to Jordan in a few lines: links to the episode page and post, and anything notable. Then **append to Lessons below** anything that went wrong or that you'd do differently.

## Lessons (append; newest last)
- Whisper mishears names. The fixes live in `episodes-src/vocab.tsv`; add new ones there rather than fixing by hand.
- Unpunctuated stream-of-consciousness speech: the transcript script paragraphs by time and marks mid-sentence breaks with "…". That's intended.
- Cloudflare caches `audio.millillion.org`. After replacing an MP3, purge the URL or the old file keeps being served.
- `audioBytes` must equal the exact MP3 size. Re-tagging changes the size, so update it after the final file is made.
- DeepFilterNet 0.5.6 needs the torchaudio import patch; `setup_audio_tools.sh` applies it.
- Apple Podcasts Connect sometimes errors on the first "Add"; retrying works. Cloudflare blocks Python's default urllib user agent, so use curl for checks.
- Jordan found the original "in" scale intro too dark, and high ringing notes sounded like mic feedback. Keep the intro bright (yō scale) and free of sustained high notes.
